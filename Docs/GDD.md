# 기획서 (GDD) v0.1

확정된 결정만 적는다. 바뀌면 이 문서를 먼저 고친다.

## 1. 한 줄 정의

검과 마법의 이세계를 1인칭으로 여행하는 스토리 중심 어드벤처. 출시가 목표다.

## 2. 핵심 경험

플레이어는 낯선 세계에 떨어진 여행자다. 마법을 배우며 길을 따라 걷고, 지형과 하늘이 바뀌는
풍경 속에서 설명되지 않는 이상현상을 마주친다. 길 위에서 만난 소수의 동행과 관계를 쌓고,
가끔 피할 수 없는 대치를 마법으로 넘긴다.

10분을 플레이하면 "다음 언덕 너머가 궁금하다"는 감정이 남아야 한다.

## 3. 축과 비중

제작의 축은 **여행 풍경과 이상현상**이다. 종족과 인물은 소수 정예로 둔다.

| 요소 | 플레이 시간 비중 | 내용 |
|---|---|---|
| 탐험·여행 | 약 45% | 풍경, 이상현상 발견, 길 찾기 |
| 스토리·교류 | 약 30% | 대화, 동행, 야영, 마을 생활 |
| 전투 | 약 20~25% | 손으로 배치한 대치 장면. 반복 사냥 없음 |

비중은 프로토타입에서 걸어 본 뒤 조정한다.

## 4. 전투

- 마법 중심, 검은 보조
- 적 종류는 적게 두고 조우 설계로 변주한다
- 전투는 사건이다. 조우마다 이유와 장소가 있다

## 5. 첫 구역 (버티컬 슬라이스)

이 구역이 재미있다고 확인된 뒤에만 범위를 넓힌다.

- 공간: 출발 마을 외곽 → 숲길 → 이상현상이 있는 폐허. 걸어서 15~20분
- 이상현상 1개: 중력이 뒤틀려 돌이 떠 있는 지대 (가안)
- NPC 2~3명: 스승 또는 동행 1명, 마을 주민 1~2명
- 마법 3종: 공격 1, 방어 또는 이동 1, 탐험용 1
- 적 2종, 조우 3회. 마지막은 폐허에서의 대치
- 시스템: 이동, 상호작용, 대화, 시간대 변화, 간단한 야영

## 6. 역할

| 담당 | 범위 |
|---|---|
| 경주 | 플레이 테스트와 피드백, 아트 디테일(어셋, 동선 다듬기, 라이팅), 캐릭터(Tripo 3D 생성 후 리깅·모션) |
| Claude | 기획, 시나리오, 게임플레이 C++ 코드, 프로토타입 레벨(그레이박스), 시스템 설계, 아트·어셋 포함 개선 제안 |

## 6-1. 도구

- 엔진: Unreal Engine 5.9 프리뷰로 시작, 정식 5.9가 나오면 올린다. 프리뷰 기간에는 본 어셋을 넣지 않는다
- 캐릭터·간단한 어셋: Tripo 3D로 초안을 뽑고 경주가 다듬는다 (유료 플랜, 상업적 이용 가능)
- 원화: ChatGPT Plus

## 7. 제작 순서

1. 언리얼 프로젝트 생성 (1인칭 템플릿, C++)
2. 그레이박스로 첫 구역 동선 만들기
3. 이동, 상호작용, 대화, 시간대 변화 구현
4. 마법 3종과 적 1종으로 전투 프로토타입
5. 걸어 보고 비중과 범위 조정
6. 아트 교체, NPC와 스토리 연결

## 8. 미정

- 아트 스타일 기준 (셀 셰이딩 여부, 색 방향)
- 주인공과 세계의 설정, 제목
- 캐릭터 얼굴 표정 처리 방식

## 9. 구현 현황

| 낮밤 (시계, 태양 회전) | 빌드와 플레이 확인됨 |
| 공격 마법, 마나, 체력, 허수아비 | 빌드와 플레이 확인됨 |

| 첫 구역 그레이박스 생성 명령, 떠 있는 돌, 저중력 지대 | 코드 작성됨. 빌드 확인 전 |
| 야영, 나머지 마법 2종, 대화 선택지, 길찾기 | 미착수 |

## 10. 작업 방식

Claude가 코드를 올리면 경주는 에디터를 닫고, GitHub Desktop에서 Pull을 한 뒤,
`RebuildAndOpen.bat`을 실행한다. `Isekai.uproject`를 직접 열면 새 코드가 빌드되지 않는다.

## 11. 첫 구역 그레이박스

에디터 콘솔에서 `Isekai.BuildGreybox`를 실행하면 현재 레벨에 만들어진다.
만든 액터에는 `IsekaiGreybox` 태그가 붙고, 다시 실행하면 그 액터만 지우고 새로 만든다.
그레이박스 액터를 직접 고치면 다음 실행 때 사라지므로, 고칠 내용은 Claude에게 전달해 코드에 반영한다.
아트 작업용 액터는 태그가 없으므로 남는다.

동선(약 840m): 마을 마당 → 마을 문 → 숲길 → 공터(적 2) → 고갯길(절벽 사이 오르막) → 고지대(적 1) → 폐허 단상(적 3, 저중력, 떠 있는 돌).

맵은 `Content/Maps/L_FirstArea`로 저장한다. 기본 맵 설정이 이 경로를 가리킨다.
